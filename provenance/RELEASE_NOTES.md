# Private reproducibility snapshot 1.0.0

This snapshot consolidates the final four-model experiment into a conventional
research repository. It includes:

- exact compressed raw outputs and runtime records for all four models;
- a harmonized 3,200-row prediction file;
- reproducible CI, EI, evidence-advantage, and Evidence Override analyses;
- question-clustered bootstrap code and validated summary outputs;
- cross-model agreement and mechanically selected case analyses;
- regenerated Figure 2 and paper-ready LaTeX rows;
- exact model, GGUF, chat-template, and `llama.cpp` provenance; and
- final model-specific inference source snapshots without model weights.

Conversational records, temporary working files, obsolete output directories,
and fabricated version history are not part of the repository.
