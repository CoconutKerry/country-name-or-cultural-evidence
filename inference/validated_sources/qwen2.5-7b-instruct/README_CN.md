# 文化对齐审计：国家标签与群体证据

## 修复状态（2026-08-30）

仓库中 2026 年 7—8 月生成的主实验、试点、消融结果及分析报告仅为
溯源材料，**不能作为有效实验结果引用**。审计确认原实现存在以下关键问题：

- 实际评分对象是完整答案文本的第一个 token，而不是界面中显示的
  `A/B/...` 选项标签；
- 分析时仅按 `(question_id, country)` 分组，覆盖了不同证据来源国的有向
  实验单元；
- Jensen–Shannon 散度混用了自然对数与以 2 为底的定义；
- 纳入了非全国样本、旧全国样本以及答案模式不兼容的数据；
- 数字型选项与 JSON 字符串键不一致，可能使证据分布被错误读取为零。

v2 已修复上述实现问题，但尚未运行四模型正式实验。

## 修复后的实验单元与评分

唯一实验单元为有向三元组：

```text
(question_id, 标签国家, 证据来源国家)
```

反向组合是不同实验单元。每个单元包含 `baseline`、`country_label`、
`population_evidence`、`conflict` 四个条件。

提示词要求模型预测一名随机抽取受访者所选的一个答案标签。程序计算
`A/B/...` 标签完整续写序列的似然，再将概率映射回语义选项；不再使用答案
文本首 token。正式推理使用锁定提交版本的模型/分词器及各自聊天模板，按
`(问题, 目标国家)` 确定性打乱选项，并记录运行环境、提示词及模板哈希。
所有 JSD 均采用以 2 为底的定义，范围为 `[0, 1]`。

Evidence Override 定义为：

```text
JSD(预测, 标签国分布) - JSD(预测, 证据国分布)
```

正值表示预测更接近证据国分布，负值表示更接近标签国分布。
该指标只是冲突条件下的有符号接近度，不能单独证明证据在因果上造成了
“覆盖”。CI/EI 按唯一 `(模型, 问题, 目标国家)` 计算一次，EO 则按完整有向
三元组计算，避免同一目标国家因多个冲突国而被重复加权。

## 数据修复

保留 `dataset_v1.json` 作为来源记录。以下命令生成 v2 数据、200 个成对平衡
的有向实验单元及排除统计：

```bash
python -m scripts.repair_data
```

v2 采用保守策略：排除明确标注的非全国样本与旧全国样本；保留当前全国
样本并规范显示名称；统一数字/文本选项键；只去除明确的缺失/拒答，保留
`Both/Neither/None/Depends` 等可能具有实质意义的答案；隔离混合模式、未经
审核的语义别名、`Total N=` 解析伪项、无法解析的占位符及缺少调查年份的
相对时间问题，并排除实质回答质量不超过 50% 的样本。当前重建保留 1,038
个问题、18,801 个问题—国家单元，并生成
200 个平衡有向单元。原压缩包没有调查年份、轮次及样本量字段，因此无法在
本仓库中重新验证这些标准，论文中必须保留这一限制。

## 测试与烟雾测试

```bash
python -m unittest discover -s tests -v

HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
python -m src.main --mode smoke --config config_smoke.yaml \
  --output experiments/smoke/results_smoke.json

python scripts/validate_smoke.py experiments/smoke/results_smoke.json
```

烟雾测试严格限定为一个合成后端、两个互为反向的有向单元、四个条件、八条
记录。其数值仅用于验证流程，并在输出中标记为
`scientific_inference: false`。它不是实际 LLM 的单模型烟雾测试；在合适的
GPU 环境中仍需完成真实模型烟雾测试。

## 正式实验保护

所有非烟雾模式都会在数据/模型加载前停止，除非显式提供
`--allow-full-run`。在真实单模型烟雾测试、数据单元、统计计划、计算环境与
预算获得批准前，不应使用该参数。正式配置仍为四个模型、150 个有向单元和
四个条件。

详细审计见 `audit/AUDIT_REPORT.md`。
