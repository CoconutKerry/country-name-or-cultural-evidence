# Licensing status

No repository-wide public code license has been selected in this private review
snapshot. The authors should choose a code license before public release.

The repository contains derived data from GlobalOpinionQA and source material
adapted from Pew Global Attitudes and World Values Survey data. Redistribution
of processed records must be reviewed against the applicable source terms.
Model weights are not included. Each GGUF remains subject to its repository and
upstream model licenses. `llama.cpp` remains subject to its own license.

The files under `inference/validated_sources/` are preserved research source
snapshots. Their inclusion here does not alter third-party licensing terms.
